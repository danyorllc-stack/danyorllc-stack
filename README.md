## What I Build For Clients

| Service | What you get |
| :--- | :--- |
| **RAG Systems** | Private knowledge assistants, contextual document search, citation-grounded answers over your proprietary data. |
| **Edge AI APIs** | Streaming, low-latency, globally distributed endpoints on Cloudflare Workers — no cold starts. |
| **Autonomous Agents** | Multi-step reasoning, dynamic tool usage, and enterprise workflow automation with LangGraph. |
| **Multi-Tenant SaaS** | RLS, strict tenant isolation, embeddable widgets with HMAC auth, usage metering. |
| **Production Hardening** | Auth + MFA, rate limiting, secret hygiene, observability, security best practices. |
| **Cost & Latency Tuning** | Token budgeting, caching layers, retrieval reranking — cheaper and faster on the same model. |

## How an Engagement Runs

```text
  1  Discovery call       ->  scope, success metrics, constraints        day 0
  2  Architecture doc     ->  data flow, tenancy model, cost model       day 1-2
  3  Sprint build         ->  fixed price, demo every 48h                week 1-3
  4  Hardening + handoff  ->  tests, docs, runbook, observability        final days
```

---

## Architecture I Default To

```text
   Client / Widget
        |
        v
   Cloudflare Worker  (Hono)  -- auth, HMAC verify, rate limit
        |
        +--> Retrieval  ->  Postgres + pgvector   (RLS per tenant)
        |
        +--> LLM call   ->  streamed tokens back to client
        |
        +--> Queues / Durable Objects  -> async jobs, agent state
```
