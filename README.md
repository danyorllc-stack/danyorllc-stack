## Architecture I Default To

```text
   Client / Widget
        |
        v
   Cloudflare Worker  (Hono)  -- auth, HMAC verify, rate limit
        |
        +--> Retrieval  ->  Postgres + pgvector   (RLS per tenant)
        |
        +--> LLM call   ->  streamed tokens back to client
        |
        +--> Queues / Durable Objects  -> async jobs, agent state
        |
        +--> Traces / metrics  ->  latency, tokens, cost per request
```

## Engineering Principles

| # | Principle | In practice |
| :---: | :--- | :--- |
| 01 | **Ship at the edge** | Global by default, no cold starts, latency measured from the user's region. |
| 02 | **Isolate tenants at the data layer** | RLS and scoped keys, never "filter in application code and hope". |
| 03 | **Stream everything** | Perceived latency beats total latency; first token in under a second. |
| 04 | **Ground every answer** | Citations or nothing — retrieval quality before model size. |
| 05 | **Budget tokens like money** | Caching, reranking, and context trimming before upgrading the model. |
| 06 | **Hand off, don't hoard** | Tests, runbooks, and observability so your team owns it after day one. |
